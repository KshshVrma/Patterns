# Patterns

This project is a collection of common design patterns implemented in Java using Spring Boot.

## Project Structure

The project is organized into the following packages:

- `com.Pattern.Patterns.Behavioral`: Contains behavioral design patterns.
- `com.Pattern.Patterns.Creational`: Contains creational design patterns.
- `com.Pattern.Patterns.Structural`: Contains structural design patterns.
- `com.Pattern.Patterns.Problems`: Contains solutions to common problems using design patterns.

## Implemented Patterns

### Structural Patterns

- **Decorator:** The Decorator pattern is implemented in the `Structural.Decorator` package. This pattern allows behavior to be added to an individual object, either statically or dynamically, without affecting the behavior of other objects from the same class.

## How to Run

This project uses Maven as a build tool. To run the project, you can use the following command in the `Patterns` directory:

```bash
./mvnw spring-boot:run
```

This will start the Spring Boot application.
